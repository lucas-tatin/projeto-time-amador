# Projeto Time Amador

Site do Marmita Quente FC, um time de futebol amador do bairro. A ideia é ter uma página simples onde a galera possa conhecer o time, ver quem faz parte do elenco (com foto, posição, número da camisa e gols de cada jogador) e acompanhar os próximos jogos, com data, adversário, local e horário. O projeto está sendo feito com React, TypeScript e Tailwind CSS como trabalho de conclusão da disciplina.
